Disqus is a hosted web comments and community discussion service used by publishers and bloggers to add threaded commenting, social sharing, and audience engagement features to their sites without running their own backend. The Disqus Public API lets developers read and write comments, threads, forums, users, and category data and integrate Disqus communities into custom applications. Authentication uses OAuth 2.0 plus an API key and secret, with all REST endpoints served from disqus.com/api/3.0/.

**APIs.json:** [https://raw.githubusercontent.com/api-evangelist/disqus/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/disqus/refs/heads/main/apis.yml)

## APIs

### Disqus Public API

REST API for reading and writing Disqus comments, threads, forums, users, categories, and moderation data. Endpoints are served from https://disqus.com/api/3.0/ and authenticated via OAuth 2.0 access tokens combined with an application API key and secret passed as query parameters.

- **Human URL:** [https://disqus.com/api/docs/](https://disqus.com/api/docs/)
- **Base URL:** `https://disqus.com/api/3.0/`
